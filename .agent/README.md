# `.agent/` — состояние проекта, общее для всех агентов

Здесь лежит **состояние**, а не инструкции. Инструкции у каждого агента свои
(`.claude/`, `.kimi-code/`), а состояние — одно на всех: иначе Claude, Kimi и следующий агент
начнут работать по разным картинам мира.

Точка входа с общими правилами — `AGENTS.md` в корне. Claude Code подтягивает его импортом
`@AGENTS.md` из `CLAUDE.md`; Kimi — ссылкой из `.kimi-code/AGENTS.md`.

---

## Живое — читать и обновлять

| Файл | Что | Когда обновляется |
|---|---|---|
| `BACKLOG.md` | **указатель**: ссылки на открытые Issues, P2-долг, вопросы владельцу | при сверке бэклога с кодом |
| `BLOCKERS.md` | активные блокеры и решённые с доказательством | когда блокер появился или снят |
| `DECISIONS.md` | принятые решения — ответ на «а почему у нас так» | когда решение принято, а не потом |
| `SESSION_LOG.md` | что сделано в сессии, с доказательствами | в конце каждой сессии |
| `SESSION_LOG.archive.md` | то же, старое | при архивации |

**План работ здесь не живёт.** Он в открытых GitHub Issues; `BACKLOG.md` — указатель на них,
витрина — `ai-launcher/BOARD.md`.

## Рабочая площадка конвейера

`runs/<task-id>/` — `task.md`, `spec.md`, `research/`, `review/findings.md` на время работы над
задачей. **В `.gitignore`**, переживает удаление worktree и не смешивается с файлами выше.
Соглашение — скилл `pipeline-workspace`.

⚠️ Черновики конвейера никогда не пишутся в файлы выше, и `git add .agent/runs/` не делается.

## ⚠️ Не поддерживается

| Файл | Состояние |
|---|---|
| `METRICS.md` | «обновляется каждую пятницу» — последнее живое обновление Sprint 1, июль 2026 |
| `PLANNING_HANDOFF.md` | датирован 2026-05-30, ссылается на `scripts/kimi-task.sh`, которого нет |

Оба ещё числятся источниками в шести Kimi-скиллах, поэтому не удалены и не перенесены — это
решение стороны Kimi. Пока они здесь, **верить им нельзя**: верить надо коду, Issues и
`PROJECT_CONTEXT.md`.

## Правила

1. **Состояние — сюда, инструкции — в `.claude/` и `.kimi-code/`.** То, что лежит в
   `.claude/agent-memory/`, читает только Claude; то, что здесь, читают все.
2. **«Сделано» пишется с доказательством** — номер PR, SHA, вывод прогона. Без него это
   «кажется, сделано», и через месяц одно от другого не отличить.
3. **Устаревший файл либо чинится, либо получает плашку.** Документ, который врёт, но выглядит
   авторитетно, хуже отсутствующего: агент его прочтёт и поверит.
