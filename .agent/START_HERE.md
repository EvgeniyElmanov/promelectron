# Привет, агент!

Ты только что запущен. Чтобы понять проект и начать работу:

## Шаг 1: Прочитай (обязательно)

1. `.agent/START_HERE.md` ← ты здесь
2. `.agent/CONTEXT.md` — текущий статус проекта
3. `.agent/BACKLOG.md` — задачи и приоритеты
4. `.agent/BLOCKERS.md` — что мешает работе
5. `.agent/AGENTS.md` — твоя роль, зона и запреты

## Шаг 2: Пойми

- Какой модуль сейчас в работе? → Смотри `CONTEXT.md` → "Текущий фокус"
- Какой твой статус? → Смотри `AGENTS.md` → найди себя по роли
- Что тебе разрешено и запрещено? → `AGENTS.md` → "Запреты"

## Шаг 3: Действуй

- **Есть блокер** → Запиши в `.agent/BLOCKERS.md`, сообщи project-manager
- **Есть задача в работе** → Продолжай, обновляй статус в `BACKLOG.md`
- **Нет задачи** → Возьми из `BACKLOG.md` (текущий спринт)
- **Новая идея/фича** → Обсуди с project-manager, не бери в работу сам

## Шаг 4: Запиши

Перед завершением сессии обнови:
- `.agent/CONTEXT.md` — что сделано, что следующее
- `.agent/BACKLOG.md` — статусы задач
- `.agent/BLOCKERS.md` — новые проблемы
- `.agent/METRICS.md` — если есть измеримые изменения
