# /skill:sessions — какие сессии открывать сейчас

> **ЯЗЫК / LANGUAGE:** Пользователь общается на русском. Все ответы пользователю и артефакты пиши на русском. Стремись рассуждать на русском, но если reasoning уходит на английский — это не ошибка; главное, чтобы финальные ответы и артефакты были на русском. Код, команды, идентификаторы, пути и технические термины оставляй в оригинале.

Посчитай **текущую волну** и выдай её пронумерованными терминалами с готовыми командами.
Ничего не выдумывай — выводи из живого состояния.

**Бэклог (GitHub Issues) — источник истины. Лончер — способ взять issue в работу, а не работа,
существующая только в лончере.**

> Замки, форма борда и порядок сверки — **[`ai-launcher/CONVENTIONS.md`](../../../ai-launcher/CONVENTIONS.md)**.

---

## Порядок

1. **Прочитай состояние.** `ai-launcher/BOARD.md` — статусы, замки, зависимости. Сверь фактами:
   ```bash
   git worktree list
   git branch -a --sort=-committerdate | head -20
   gh pr list --repo AutonomaCo/promelectron --state open --limit 20
   gh issue list --repo AutonomaCo/promelectron --state open --limit 100 \
     --json number,title,labels,url
   git log --oneline -5
   ```
   Расхождение — чини борд (`/skill:board refresh`), а не отчёт владельцу.

2. **Отбери волну.** Пункт входит, если статус 🟢, **все** его замки свободны и не заняты
   другим пунктом волны, зависимости закрыты. Пункт с замком `all` идёт **один**.

3. **Проверь, что промпт есть** в `ai-launcher/prompts/`. Нет — либо напиши сейчас, либо покажи
   пункт в «кнопки нет» и объясни, чего не хватает. Кнопку без промпта не выдавай: сессия
   начнёт с чистого листа и придумает задачу сама.

4. **Выдай терминалы.** По блоку на сессию:

   ```
   ### Терминал 1 · #186 · флаки cart-select.spec.js · замок e2e

   make ai PROMPT=ai-launcher/prompts/e2e_186-cart-select-flaky.prompt.txt

   Что делает: ...   Чего ждать: ...   Тебя спросят про: ...
   ```

   Команда **всегда** `make ai PROMPT=…`, не `kimi …` напрямую: борд общий на двоих, и у
   коллеги та же строка запускает claude.

5. **Скажи, чего НЕ запускать и почему.** Это половина ценности ответа.

6. **Обнови борд**, если замки или статусы разошлись с тем, что там написано.

---

## Правила

- Не предлагай параллелить два пункта с общим замком. Никогда.
- Не предлагай то, что ждёт владельца (🟡/🔴) — выноси отдельным списком «сначала ответь».
- Реалистично оценивай нагрузку на машину. `make test-e2e` поднимает docker-compose со всем
  стеком: две параллельные E2E-сессии на одном хосте передерутся за порты и БД.
  `make test-backend` и `make test-onec-mock` сериализованы через `flock`
  (`TEST_BACKEND_LOCK`) — они не сломаются, но вторая сессия будет ждать первую, и это надо
  сказать владельцу, а не выдавать за параллельность.
