# Language Rule / Языковое правило

> **Перемещено.** Чтобы правило не расходилось по копиям, единственный источник
> истины о языке теперь — [Rule: Agent Commons](./agent-commons.md) > **Language Rule /
> Языковое правило** (там же — точная преамбула для субагентов).

Коротко: при русскоязычном пользователе финальные ответы, отчёты и артефакты
(`task.md`, `spec.md`, `findings.md`, `SESSION_LOG.md`, комментарии к PR) пишутся на
русском; в рассуждении нужно стремиться к русскому, но thinking mode у Kimi K2.7-Code
принудительный и его язык промптом надёжно не контролируется. Код, команды,
идентификаторы, пути и технические термины — всегда в оригинале.

Полную формулировку и правила делегирования субагентам см. в
[agent-commons.md](./agent-commons.md).
