## Опыт работы / Проекты

### AI-driven Python Backend Developer (pet-project Promelectron)
*[Месяц 2024 — настоящее время]*

- Спроектировал и внедрил **AI-driven development pipeline** для продукта на базе Kimi Code CLI:
  оркестрация subagents (architect → developer → reviewer → QA), изолированные git worktrees,

- Разработал backend маркетплейса на **FastAPI** с **async SQLAlchemy 2.0**, PostgreSQL, Redis, Celery:
  40+ REST API endpoints, каталог, корзина, заказы, админка, управление получателями.

- Реализовал интеграцию с **1C ERP**: синхронизация товаров (SKU, цены, остатки, категории, габариты)
  через REST API по расписанию (Celery + CronJob в Kubernetes), создание/обновление/деактивация товаров.
- Реализовал **OAuth Yandex ID / Google ID**, email-верификацию, сброс пароля, rate limiting, feature flags.
- Настроил инфраструктуру и CI/CD: **Docker → GitHub Actions → Harbor → Kubernetes (Helm)**,
  self-hosted runner, SOPS-шифрование секретов, фоновый `job_worker`.
- Работал с Kubernetes: развёртывание подов, `kubectl port-forward`, `kubectl exec/logs`, Helm values,
  debugging сервисов в кластере через k9s и CLI.
- Покрыл проект тестами: **backend 335/335 ✅, frontend 245/245 ✅, E2E 108/108 ✅**.

**Технологии:** Python, FastAPI, SQLAlchemy, PostgreSQL, Redis, Celery, Vue 3, Docker, Kubernetes,
Helm, GitHub Actions, pytest, Playwright, Kimi Code CLI, LLM-агенты, **1C ERP REST API**.
