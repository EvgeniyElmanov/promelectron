## 🗺 Дальнейший план

### Sprint 3 — Поиск, фильтры и UX
**Цель:** сделать каталог удобным для навигации и поиска.

- **Backend:**
  - Поиск товаров по названию и описанию (`/products/?q=...`)
  - Фильтрация по категории (`/products/?category_id=...`)
  - Фильтрация по цене (`/products/?min_price=...&max_price=...`)
  - Сортировка (`/products/?sort=price_asc|price_desc|rating`)
- **Frontend:**
  - Работающий поиск в SearchBar
  - Активные CategoryChips с фильтрацией
  - Слайдер/поля цены для фильтра
  - Селект сортировки
  - **Toast-уведомления** (замена `alert()` в корзине и заказах)
- **Тесты:** backend + frontend + e2e

### Sprint 4 — Админ-панель и управление контентом
**Цель:** дать админам и поставщикам инструменты управления.

- **Backend:**
  - CRUD категорий (админ)
  - Upload изображений товаров (`/products/{id}/images`)
  - Пагинация с `total_count` в ответе
- **Frontend:**
  - Полноценная Admin Panel (таблица товаров, пользователей, заказов)
  - Страница "Мои товары" для поставщика
  - Загрузка изображений в форме товара
- **Тесты:** полный покрытие

### Sprint 5 — Корзина и оформление заказа v2
**Цель:** превратить корзину и заказы в полноценный checkout flow.

- **Backend:**
  - Адрес доставки в модели Order
  - Валидация наличия товара перед заказом
  - Promo-коды (скидки)
- **Frontend:**
  - Переверстать Cart.vue в мобильный Ozon-стиль
  - Страница checkout (адрес, доставка, оплата)
  - Skeleton-загрузки вместо текстовых спиннеров
  - Бесконечный скролл в каталоге (вместо кнопки "Показать ещё")
- **Тесты:** e2e на полный flow покупки

### Sprint 6 — Интеграции и инфраструктура
**Цель:** production-ready функции.

- **Backend:**
  - Redis для кэширования популярных товаров
  - Celery + RabbitMQ для фоновых задач (отправка email, очистка корзин)
  - Rate limiting на API
  - Health check endpoint
- **Frontend:**
  - SSR или хотя бы prerender для SEO
  - Meta-теги для PDP
  - Service Worker для офлайн-корзины
- **DevOps:**
  - Docker Compose production
  - GitHub Actions CI/CD
  - Nginx reverse proxy

### Sprint 7 — AI / ML фичи (опционально)
- Рекомендации товаров (похожие товары, "вам может понравиться")
- Поиск с опечатками (fuzzy search)
- Автоматическая категоризация товаров

## 🎯 Рекомендация: следующий шаг

**Sprint 3 — Поиск, фильтры и Toast-уведомления**

Причины:
1. **Максимальный UX-эффект** — поиск и фильтры это то, чем пользователи пользуются каждый день
2. **Замена `alert()`** — сейчас в корзине и заказах используются нативные `alert()`, что выглядит непрофессионально
3. **Backend уже почти готов** — у нас есть все модели, нужно только добавить query-параметры в `/products/`
4. **Можно разбить на срезы:**
   - Срез 1: Поиск по названию + Toast-система
   - Срез 2: Фильтр по категории
   - Срез 3: Фильтр по цене + сортировка
   - Срез 4: E2E тесты

**Оценка:** 2–3 часа работы.
