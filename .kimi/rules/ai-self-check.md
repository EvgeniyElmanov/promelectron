# AI Self-Check — Правила для AI-ассистента

> Этот файл читается AI-ассистентом (Kimi CLI) перед работой.  
> Цель: минимизировать галлюцинации, ошибки и забытость.

---

## Перед каждым ответом

1. **Если утверждаешь что-то о коде** — проверь через `ReadFile` или `Grep`.
   - ❌ Неправильно: «В проекте используется X» без проверки
   - ✅ Правильно: Прочитал файл, убедился, что X используется

2. **Если предлагаешь изменение** — проверь, что оно не сломает существующее:
   - Найди все места, где используется изменяемый код (`Grep`)
   - Убедись, что тесты покрывают эту область

## Перед каждым редактированием

3. **Покажи diff** перед `StrReplaceFile` или `WriteFile`:
   ```
   Будет изменено:
   --- old
   +++ new
   ```
   Это даёт пользователю прозрачность.

4. **Проверь trailing slash** для API endpoints:
   - FastAPI: `@router.get("/items/")` → frontend: `api.get('/items/')`
   - Неправильно: `api.get('/items')` → 307 redirect

## После каждой работы

5. **Обнови `.agent/SESSION_LOG.md`** — кратко: что сделано, файлы, риски.
   - Не жди, пока пользователь напомнит.

6. **Обнови `PROJECT_CONTEXT.md`** — если:
   - Появилась новая фича
   - Изменилась архитектура
   - Новый endpoint
   - Новый env var

7. **Не удаляй файлы** без явного разрешения пользователя.
   - Исключение: временные файлы, которые сам создал

## Анти-паттерны (чего НЕ делать)

- ❌ Не гадай о структуре проекта — всегда проверяй `ls` / `Glob`
- ❌ Не предполагай, что файл существует — проверяй перед чтением
- ❌ Не пиши «я думаю» — пиши «я проверил и увидел»
- ❌ Не забудь обновить `BACKLOG.md` если задача из спринта выполнена
- ❌ Не используй `rm -rf` — никогда
