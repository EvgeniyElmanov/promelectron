# /backlog-add

This command is implemented as the **`backlog-add` skill** — the single source of truth lives in
[`.claude/skills/backlog-add/SKILL.md`](../skills/backlog-add/SKILL.md).

Capture an idea/TODO into the **GitHub backlog**: create a GitHub Issue on `AutonomaCo/promelectron`
and add it to the GitHub Project board (Todo). Interactive — quick one-liner, or a background agent
that enriches the issue body with current session context. Не локальный файл — это GitHub Issues.

Arguments: `<идея / TODO для бэклога>`
