Выше импортирован `AGENTS.md` — общий индекс для всех агентов проекта. Ниже — только то, что
относится к Claude Code и не имеет смысла для остальных.

## Что где лежит

Содержание — в общем каталоге `.agents/`, здесь только привязка к Claude Code.

```
.agents/                          ← общее для всех агентов проекта, правится ЗДЕСЬ
├── skills/      26 сценариев     ← .claude/skills/<имя>  — симлинк
├── conventions/  8 конвенций     ← .claude/rules/<тема>.md — симлинк
└── agents/       7 ролей         ← .claude/agents/<имя>.md читает указателем

.claude/                          ← только Claude-специфика
├── skills/      симлинки в .agents/skills/ — дают слэш-команды по имени
├── rules/       симлинки в .agents/conventions/ — грузятся по paths:
├── agents/      7 субагентов: шапка Claude + указатель на .agents/agents/
├── settings.json / settings.local.json
└── .github-project.json    id доски и полей
```

⚠️ **Правь оригинал в `.agents/`, а не файл под `.claude/`.** Второе — симлинк; правка «мимо»
разведёт агентов по разным правилам. Симлинки для скиллов и правил документированы явно;
для субагентов — нет, поэтому там указатель, а не ссылка.

Новый скилл: создать `.agents/skills/<имя>/SKILL.md`, затем
`ln -s ../../.agents/skills/<имя> .claude/skills/<имя>`. Регистрируется **на старте сессии**.

## Скиллы, а не команды

Каталога `.claude/commands/` здесь **нет намеренно**. Апстрим слил команды в скиллы: файл
`commands/x.md` и `skills/x/SKILL.md` оба дают `/x`, но **при совпадении имени побеждает
скилл**. В этом репозитории когда-то лежало 17 файлов-команд с теми же именами, что скиллы, —
все они молча не исполнялись. Удалены 2026-09-05.

Полезная шапка скилла:

| Поле | Когда ставить |
|---|---|
| `description` + `when_to_use` | всегда — по ним Claude решает, грузить ли скилл |
| `disable-model-invocation: true` | сценарии с побочными эффектами (push, PR, деплой) — запускает только человек |
| `user-invocable: false` | фоновые справочники, которые читает только агент (`*-conventions`) |
| `allowed-tools` | предодобрить **читающие** вызовы; запись и push сюда не писать |
| `argument-hint` | подсказка автодополнения |

Имя каталога = имя команды. Поле `name` в шапке — только подпись в списке.

## Правила и их `paths:`

`.claude/rules/*.md` (симлинки на `.agents/conventions/`) без `paths:` грузятся каждую сессию;
с `paths:` — когда Claude открывает подходящий файл.

⚠️ **`paths:` должны совпадать с реальной раскладкой.** Здесь код лежит в `backend/src/app/`,
а не в `backend/app/`. Четыре правила были написаны под `backend/app/**` и из-за этого не
загружались вообще — а их содержимое к тому же описывало чужой проект. Меняешь правило —
проверь, что его `paths:` матчатся:

```bash
python3 - <<'CHECK'
import pathlib, re, glob
for f in pathlib.Path(".agents/conventions").glob("*.md"):
    m = re.search(r"^paths:\n((?:\s+-\s+.*\n)+)", f.read_text(encoding="utf-8"), re.M)
    if not m: continue
    for p in re.findall(r'"([^"]+)"', m.group(1)):
        if p.startswith(".worktrees"): continue   # их нет, пока никто не работает — это норма
        if not glob.glob(p, recursive=True):
            print(f"{f.name}: ни одного файла под {p}")
CHECK
```

## Память субагентов

`.claude/agent-memory/<агент>/` — то, что субагент накопил между сессиями. Каталог не для
проектного состояния: состояние живёт в `docs/` и читается всеми агентами, а не одним.

## Проверки перед коммитом

**будет ждать**. Это очередь, а не параллельность — так и говори владельцу.
