# 🅑 Бэкенд

---

> <a id="i-210"></a>🟢 **[#210](https://github.com/AutonomaCo/promelectron/issues/210)** · вебхук ЮKassa: подпись пропускается, сумма не сверяется — `lock: backend` · **P0** · **свободен**

```bash
make ai PROMPT=ai-launcher/prompts/backend_210-yookassa-webhook-signature.prompt.txt
```

`payment_service.py:417` проверяет подпись **только если заголовок пришёл**: запрос без
`X-YooKassa-Signature` идёт в обработку как настоящий. Отдельно — сумма из вебхука нигде не
сверяется с суммой платежа в БД.

Цепочка эксплуатации замкнута: `yookassa_payment_id` отдаётся владельцу заказа в
`GET /payments/{id}/`, то есть покупатель знает идентификатор и может послать себе
`payment.succeeded`. Переход в `paid` запускает создание отправления в СДЭК — товар уезжает
без оплаты.

Тесты это не поймают: `test_payments.py:374` сам шлёт вебхук без подписи и ждёт успеха, то есть
текущее поведение закреплено как правильное.
