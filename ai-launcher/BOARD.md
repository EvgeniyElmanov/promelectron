> <a id="i-220"></a>🟢 **[#220](https://github.com/AutonomaCo/promelectron/issues/220)** · rate limit: спуфинг X-Forwarded-For, гостевой заказ без лимита — `lock: backend` · **можно брать** (P1)

```bash
make ai PROMPT=ai-launcher/prompts/backend_220-rate-limit-real-ip.prompt.txt
```

`--proxy-headers` стоит с 20.05 (старая гипотеза «лимит по IP ingress-пода» не доказана), но
`--forwarded-allow-ips='*'` → лимиты обходятся подсунутым XFF; `GET /orders/guest/{id}/` —
без лимита, перебор order_id тянет чужие адреса. Объём: верификация на живом test →
`FORWARDED_ALLOW_IPS` по env (в helm — CIDR ingress) → лимит на гостевой эндпоинт → тесты →
мутация-доказательство.
