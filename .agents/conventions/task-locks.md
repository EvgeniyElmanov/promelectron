# Замки: как разводится параллельная работа

Репу ведут двумя агентами одновременно (Claude Code и Kimi Code), в отдельных worktree'ах.
Чтобы две сессии не переписали одни и те же файлы, у каждого пункта есть **замок** — область
файлов, которую он занимает. **Два пункта с одним замком параллельно не идут.**

| Замок | Что покрывает |
|---|---|
| `backend` | `backend/**` — FastAPI, сервисы, модели, Alembic, pytest |
| `frontend` | `frontend/src/**`, компоненты, композаблы, vitest |
| `e2e` | `frontend/e2e/**` — Playwright-спеки и хелперы |
| `infra` | `infra/**`, `.github/workflows/**`, Helm, SOPS, деплой |
| `docs` | `docs/**`, `README.md`, `PROJECT_CONTEXT.md`, `ARCHITECTURE.md` |
| `harness` | `.claude/**`, `.kimi-code/**`, `ai-launcher/**`, `Makefile`, `scripts/**` |
| `none` | пункт не трогает репозиторий (доступы, настройка внешнего сервиса) |
| `all` | меняет правила игры — идёт **один**, без соседей в волне |

## Обязательное

- Пункт берёт **все** замки, чьи файлы трогает. Фронт-фича, которая правит и компонент, и
  Playwright-спеку, занимает `frontend`+`e2e`. Занижённый замок и есть тот самый конфликт.
- **Замок занимается на борде ДО создания worktree** (`ai-launcher/BOARD.md`, раздел
  «🔵 В работе»). Иначе двое возьмут одно и то же.
- Замок занят другой сессией — **остановись и скажи владельцу**, а не «аккуратно рядом».
- Пункт закрыт (PR смержен) — замок освобождается в тот же момент, что и строка на борде.

Полные правила формы борда и порядка сверки — `ai-launcher/CONVENTIONS.md`.
Команды: `/board`, `/sessions`.
