# /sessions — какие сессии открывать сейчас

Посчитай **текущую волну** и выдай её пронумерованными терминалами с готовыми командами.
Ничего не выдумывай — выводи из живого состояния.

**Бэклог (GitHub Issues) — источник истины. Лончер — способ взять issue в работу, а не работа,
существующая только в лончере.**

> Замки, форма борда и порядок сверки — [`ai-launcher/CONVENTIONS.md`](../../../ai-launcher/CONVENTIONS.md).

---

## Порядок

1. **Прочитай состояние.** `ai-launcher/BOARD.md` — статусы, замки, зависимости. Сверь с
   реальностью:
   ```bash
   git worktree list
   git branch -a --sort=-committerdate | head -20
   gh pr list --repo AutonomaCo/promelectron --state open --limit 20
   gh issue list --repo AutonomaCo/promelectron --state open --limit 100 \
     --json number,title,labels,url
   git log --oneline -5
   ```
   Расхождение — чини борд (`/board refresh`), а не отчёт владельцу.

2. **Отбери волну.** Пункт попадает в неё, если:
   - статус 🟢 (не ждёт ответа владельца),
   - **все** его замки свободны и не заняты другим пунктом волны,
   - зависимости закрыты.

   Пункт с замком `all` идёт **один**, без соседей: он меняет правила игры.

3. **Проверь, что промпт есть.** Нет файла в `ai-launcher/prompts/` — либо напиши его сейчас,
   либо покажи пункт в разделе «кнопки нет» и объясни, чего не хватает. Кнопку без промпта не
   выдавай: владелец нажмёт, а сессия начнёт с чистого листа и придумает задачу сама.

4. **Выдай терминалы.** По одному блоку на сессию:

   ```
   ### Терминал 1 · #186 · флаки cart-select.spec.js · замок e2e

   make ai PROMPT=ai-launcher/prompts/e2e_186-cart-select-flaky.prompt.txt

   Что делает: ...   Чего ждать: ...   Тебя спросят про: ...
   ```

   Команда **всегда** `make ai PROMPT=…` — она нейтральна к агенту. Не подставляй вызов
   конкретного агента напрямую: чем запускается кнопка, задаётся машинно-локально в
   `Makefile.override.mk`; борд и лончер общие для всех агентов.

5. **Скажи, чего НЕ запускать и почему.** Это половина ценности ответа: «#5 не бери, он делит
   замок `frontend` с тем, что уже в работе» полезнее, чем ещё одна кнопка.

6. **Обнови борд**, если пересчитанные замки или статусы разошлись с тем, что там написано —
   иначе следующая сессия увидит устаревшую картину.

---

## Правила

- Не предлагай параллелить два пункта с общим замком. Никогда. Это не «осторожность», это
  единственный способ не разгребать конфликты в чужой ветке.
- Не предлагай то, что ждёт владельца (🟡/🔴). Такие пункты выноси отдельным списком «сначала
  ответь / сделай сам».
- Реалистично оценивай нагрузку на машину. `make test-e2e` поднимает docker-compose со всем
  стеком: две параллельные E2E-сессии на одном хосте передерутся за порты и БД.
  `make test-backend` и `make test-onec-mock` сериализованы через `flock`
  (`TEST_BACKEND_LOCK`) — они не сломаются, но вторая сессия будет ждать первую, и это надо
  сказать владельцу, а не выдавать за параллельность.
- Отвечай по-русски.
