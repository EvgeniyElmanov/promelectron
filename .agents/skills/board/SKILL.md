# /board — пульт запуска

Аргументы: `$ARGUMENTS`

Пульт — `ai-launcher/BOARD.md`. Он **витрина** открытых GitHub Issues на
`AutonomaCo/promelectron`, а не отдельный список. Расхождение между ними — всегда ошибка
борда, а не бэклога.

> **Все правила формы, замков и порядка сверки живут в
> [`ai-launcher/CONVENTIONS.md`](../../../ai-launcher/CONVENTIONS.md).** Прочитай его прежде
> чем править борд. Здесь только сценарий команды — конвенции общие для всех агентов проекта,
> и дублировать их в нескольких наборах скиллов значит гарантированно их разъехать.

## Без аргумента: показать

1. Прочитай `ai-launcher/BOARD.md`.
2. Ответь владельцу коротко и по делу (по-русски):
   - что можно брать прямо сейчас (🟢 со свободным замком),
   - что ждёт его ответа (🟡 и «только ты»),
   - что в работе и какие замки заняты,
   - **что из «⏰ Ждут условия» уже можно проверить** — см. пункт 3.
3. **Раздел «⏰ Ждут условия» — проверь условия сам, это дёшево.** Там лежат хвосты, которые
   ждут не решения владельца, а события. Условие написано проверяемым — проверь его командой,
   а не глазами: открытый PR, состояние ветки, ответ ручки, доступность внешнего сервиса.

   Наступило — **скажи об этом первым делом**, до всего остального. Не наступило — одной
   строкой, без подробностей.

   Смысл раздела в том, что такой хвост теряется незаметнее прочих: PR смержен, борд зелёный,
   пункт выглядит готовым — а проверка, ради которой всё делалось, не проведена. Молчать о
   наступившем условии значит воспроизводить ровно ту потерю, от которой раздел заведён.
4. Не пересказывай борд целиком — владелец умеет читать. Дай выжимку и ссылки на якоря.

Ничего не правь. Показ — операция только на чтение.

## `refresh`: сверить с реальностью и переписать

Борд врёт легко и незаметно: сессия умерла, ветка смёржена, замок остался занят. Сверяй
**фактами**, а не памятью. Полный порядок — раздел 5 `CONVENTIONS.md`. Кратко:

1. Живое состояние — `git worktree list`, ветки, `gh pr list`, `gh issue list --state open`,
   `git log --oneline -10`.
2. Кластер, если пункт про инфраструктуру:
   `KUBECONFIG=~/.kube/AutonomaCo kubectl -n promelectron-test get deploy,pods`.
   ⚠️ Только этот kubeconfig — дефолтный ведёт не в тот кластер.
3. Для каждого пункта в «🔵 В работе»: ветка жива? PR открыт или смёржен? Смёржен — закрой
   issue **с доказательством** (номер PR, SHA), убери с борда, освободи замок.
4. «⏰ Ждут условия» сверяй тоже — включая правило «смержено ≠ проверено».
5. Пересчитай блок «Замки заняты / Свободны». Это самое частое расхождение.
6. Синхронизируй с бэклогом в обе стороны: пункта нет в открытых Issues — убрать с борда и
   сказать владельцу; открытый issue не на борде — добавить (без кнопки, если промпта нет).
7. Обнови шапку: SHA `main` и дату.
8. Прогони `python3 scripts/check-board.py`. Красный — чини до коммита: борд правится прямым
   push'ем в `main`, ревью на нём нет.

### Доска GitHub Project

Колонки (Todo / In Progress / In Review / Done) читаются токеном со scope `read:project`.
Загрузи скилл **`github-project`** для дискавери проекта и поля Status.

Если `gh project …` отвечает `missing required scopes` — **не молчи и не выкидывай группировку
тихо**. Скажи владельцу выполнить у себя (команда интерактивная, ты её не выполнишь):

```
gh auth refresh -s project
```

а сверку доведи по `gh issue list` + веткам и PR: без колонок доски, но честно.

## Правила

- **Борд — пульт, а не журнал.** Разборы, замеры и история сюда не пишутся: они живут в issue,
  `docs/decisions/log.md`, `docs/journal/session-log.md` и `git log`. Тянет написать абзац объяснения —
  почти наверняка ему место не здесь.
- **Кнопка только там, где есть промпт** в `ai-launcher/prompts/`. Нет промпта — пункт в списке
  «заведено, но кнопки нет»: иначе владелец нажмёт, а сессия начнёт с чистого листа и придумает
  задачу сама.
- **Кнопка пишется как `make ai PROMPT=…`** — она нейтральна к инструменту. Не подставляй
  вызов конкретного агента напрямую: чем запускается кнопка, задаётся машинно-локально в
  `Makefile.override.mk`.
- **🟢 ставится, только если замок реально свободен.** Два пункта с одним замком не бывают 🟢
  одновременно — второй «в очереди за первым».
- **Не заводи issue сам без спроса.** Пункт из `docs/backlog.md`, которого нет в Issues,
  показывается в разделе «заведено локально, issue нет» — а заводить или нет, решает владелец.
- Отвечай по-русски.
