# Архитектурное описание проекта My Shop

## Общая архитектура

### Тип архитектуры
Проект использует монолитную архитектуру с разделением на бэкенд и фронтенд части. Бэкенд реализован на FastAPI (Python), фронтенд - на Vue 3. Взаимодействие между частями происходит через REST API.

### Взаимодействие фронтенда и бэкенда
- Фронтенд: Vue 3 приложение, работающее в браузере
- Бэкенд: FastAPI приложение, запускаемое на сервере
- Коммуникация: HTTP/REST API через axios
- Аутентификация: JWT токены, передаваемые в заголовке Authorization

## Бэкенд (server/)

### Основные модули и их назначение
- `api/` - REST API эндпоинты, разделенные по сущностям
- `models/` - Модели данных SQLAlchemy для работы с БД
- `schemas/` - Pydantic схемы для валидации данных
- `services/` - Бизнес-логика приложения
- `core/` - Конфигурационные файлы
- `db/` - Конфигурация подключения к БД
- `utils/` - Вспомогательные функции (аутентификация)

### Роутинг
Основные эндпоинты API (префикс /api/v1):
- `/users/` - Регистрация, аутентификация, управление пользователями
- `/products/` - Работа с товарами
- `/categories/` - Работа с категориями товаров
- `/cart/` - Работа с корзиной пользователя
- `/orders/` - Работа с заказами

### Аутентификация
- JWT токены с использованием библиотеки jose
- Хеширование паролей с помощью passlib (Argon2)
- Ролевая система: user, admin, supplier
- Защита эндпоинтов через зависимости FastAPI

### Модели базы данных
Основные сущности:
- `User` - Пользователь (роли: user, admin, supplier)
- `Product` - Товар (связан с категорией и поставщиком)
- `Category` - Категория товаров (поддерживает иерархию)
- `Supplier` - Поставщик
- `Cart` и `CartItem` - Корзина пользователя
- `Order` и `OrderItem` - Заказы и их содержимое

Связи:
- User 1:N Cart
- User 1:N Order
- Product N:1 Category
- Product N:1 Supplier
- Cart 1:N CartItem
- Order 1:N OrderItem
- Product 1:N CartItem
- Product 1:N OrderItem

## Фронтенд (client/)

### Основные страницы
- `/` (Products.vue) - Каталог товаров
- `/login` (Login.vue) - Аутентификация
- `/admin` (Admin.vue) - Панель администратора
- `/cart` (Cart.vue) - Корзина пользователя
- `/orders` (Orders.vue) - История заказов
- `/profile` (Profile.vue) - Профиль пользователя

### Роутинг
Используется vue-router с history mode. Все страницы загружаются асинхронно.

### Коммуникация с API
- Библиотека: axios
- Базовый URL: http://127.0.0.1:8000/api/v1
- Interceptor для автоматического добавления JWT токена из localStorage

## Инфраструктура

### Docker
Файл docker-compose.yml определяет два сервиса:
- `backend` - Python приложение на порту 8000
- `postgres` - База данных PostgreSQL 15 на порту 5432

Связи:
- backend зависит от postgres
- Общая Docker сеть для взаимодействия
- Персистентное хранение данных PostgreSQL в volume

### База данных
- Тип: PostgreSQL 15
- Подключение: SQLAlchemy с asyncpg драйвером
- URL подключения: postgresql+asyncpg://shop_user:shop_password@localhost/shop_db
- Миграции: Alembic (настройка присутствует, но не используются активно)
