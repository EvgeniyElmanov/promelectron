C4-диаграммы (контекст, контейнеры) в `.drawio` + `.svg`. Регенерация — `scripts/docs/gen_diagrams.py`.
См. [`architecture/README.md`](architecture/README.md).

синхронизация каталога с 1С. См. [`flows/README.md`](flows/README.md).

## Правила

1. **Устаревший документ, выглядящий авторитетно, хуже отсутствующего.** Документ, переставший
   быть правдой, либо чинится, либо уезжает в `archive/` с плашкой и датой — но не остаётся
   лежать как есть.
2. **Один факт — одно место.** Расходящиеся копии одного и того же неизбежно разъезжаются;
   вместо копии ставь ссылку.
3. **В корне репозитория живёт только то, что читают каждую сессию.** Остальное — здесь.
4. **Документация агентской работы делится надвое:** правила для конкретного инструмента — в
   `.claude/` и `.kimi-code/`; общее для всех агентов — в tool-neutral файлах
   (`ai-launcher/CONVENTIONS.md`, `docs/guides/`), на которые оба ссылаются.
